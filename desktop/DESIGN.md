# 卫戍协议默认终端：拆解与桌面复刻

版本 0.1.1，2026-11-13。参照对象是默认「卫戍协议终端」，不是乌萨斯齐心团、可露希尔主题或终末地。

依据：[PRTS 终端主题一览](https://prts.wiki/w/卫戍协议/终端主题一览)及其中的[默认主题预览原图](https://media.prts.wiki/4/43/卫戍主题_卫戍协议终端_预览.png)，原图为 917 × 561。以下把实际观察与助手的桌面适配分开，尺寸和颜色为本次实现参数，不声称取得了游戏源工程。

## 结构与视觉语法

| 原版样张中的特征 | 助手中对应的实现 |
| --- | --- |
| 顶部是一条横向状态轨道，中央阶段牌突出于轨道上下边缘；两侧为较小的状态格 | 首页顶部 104 px 状态带，中央 198 px 切角阶段牌，左右分别显示回合与资金。阶段牌独立双层描边，两侧细刻度与轨道相连 |
| 盟约容器位于状态轨道下方，使用圆环、内部图形和下方短标签；激活与未激活亮度差很明显 | 独立 82 px 盟约条，42 px 双环，以进度弧和有效计数表达激活条件；名称与状态分两行。没有资料库中的原版盟约徽记，因此内部使用计数，而不伪造徽记 |
| 中央战场留给局面，底部调度区集中干员和操作；左端是等级格，操作与资金区靠右 | 首页中央承载决策记录和当前阵容，底部固定 166 px 调度区：左端等级、五个竖向候选槽、右端连接与分析操作。候选不足时保留空槽，空局不伪装成已识别对局 |
| 干员卡使用纵向画面，左上罗马等阶，顶部独立资金徽章，下方资料带，底边细线区分等阶 | 四列图鉴每格 138 px 高，横向随可用宽度均分；卡片左右各留 3 px。头像、等阶、费用、名称、盟约分别排布，费用不是名称的一部分 |
| 卡片激活/选中时青绿亮度集中在底部，并向人物区域衰减 | 选中卡使用向上的透明渐变与双层轮廓，文字反转成深色。费用徽章最后绘制，外围保留 3 px 横向、2 px 纵向遮断间隔；选中框不穿过费用图案 |
| 中央阶段牌与部分徽章使用短斜边；主要操作是醒目的平面色块 | 阶段牌 12 px 切角；面板 7 px、普通键 4 px、导航键 6 px 切角。主操作为无切角平面色块。窗口按钮仅 28—32 px，避免变成主操作视觉中心 |

## 信息优先级与颜色职责

颜色不是统一涂在全部控件上。青绿 `#14dfbb` 表达选中、激活、阶段和主要确认操作；金黄 `#e7b936` 专用于资金费用及相应经济强调；蓝色用于重新读取画面入口，呼应原版冻结等辅助操作的独立蓝色；未激活环、说明文字降低亮度。卡片等阶同时保留罗马数字，不能只靠颜色区分。

背景为中性深灰 `#191d1e`，面板 `#242b2b`。默认字号 13 px；页标题 27 px；分区标题 15 px；关键数值 39 px；卡片名称 12—13 px；盟约与辅助标注 10—11 px。以系统中文字体和紧凑数字字体实现大小、粗细、排列层级，没有打包或假称使用游戏专用字体。

阅读顺序是「局面是否可靠 → 当前阶段与资源 → 已成立/待成立盟约 → 选项与原因」。资金未知显示破折号，估算费用使用近似符号，不能以装饰数字冒充实测倒计时。实战建议和用户仍需确认的信息保留原有区分。

## 交互与动效

- 悬停提高轮廓亮度，按下有 1 px 下沉，选中保持完整可见的卡片反馈；键盘焦点使用独立细虚线。
- 页面切换使用 120 ms 的短淡入，不使用弹簧晃动或持续大范围闪烁。减少动效设置继续有效。这是桌面响应性的实现值；静态参考图不能证明原版逐帧时长，因此没有声称精确复刻游戏动画曲线。
- 悬浮终端复用紧凑状态轨道，建议分条显示，下方操作固定；文字放大后内容可滚动。最小化保留置顶表情入口，完全关闭同时隐藏面板和入口。
- 图鉴严格四列，普通、悬停、选中共用同一费用层；拖动左右分隔条时保持四列。长名称和说明在必要时省略，悬停可查看完整名称与来源信息，右侧资料保留完整文本。
- 1100 × 720 小窗口下长内容滚动，避免固定高度的立绘、按钮或底部卡槽互相覆盖；默认 1380 × 900 下完整显示首页调度区。

## 与游戏界面的差异

侧边十个功能入口、资料阅读区、识别校准和 API 配置是助手所需的桌面结构；原游戏没有对应的一比一页面。它们沿用上述层级、框线和反馈规则。中央区域展示真实助手数据，不放一张游戏截图伪装成可操作界面。原版场景、专用字体、盟约徽记与逐帧动画均没有被声称完整还原。

本次视觉检查覆盖全部十个页面、四列图鉴、1100/1380/1600 三种窗口宽度、100%/150% 悬浮文字、选中费用徽章与窗口操作。离屏检查不等于真实 PC 游戏识别验收，也不改变识别和 AI 功能既有的验证边界。
