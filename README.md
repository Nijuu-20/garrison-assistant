# 卫戍协议助手

配合《明日方舟》卫戍协议·规程使用的 Windows 桌面助手，优先适配官方 PC 端。当前版本 **0.1.23**。

## 下载与启动

在 [最新 Release](https://github.com/Nijuu-20/garrison-assistant/releases/latest) 下载 `GarrisonAssistant-0.1.23-Windows-x64.zip`，完整解压后运行 `卫戍协议助手.exe`。保留同目录的 `_internal` 和 `第三方许可`。

便携包只有程序、运行资源与必要许可证，不附带多余说明文件或校验文件。个人对局与 API 配置保存在本机用户目录，不包含在发行包中。

## 日常使用

首页依次完成 **绑定游戏并同步 → 开关 AI → 确认禁选 → 确认阵容**。下方可核对成员、查看建议、锁定攻略路线、选择追踪目标。

- **资料图鉴**：干员、盟约、装备、策略 / 指令与并排对比。干员四列排布，支持按钮筛选、详情分页与普通 / 精锐切换。
- **阵容攻略**：本地署名攻略、作者变体、自建记录、收藏与删除。第 3 回合起主动推荐满足本局条件的可追踪阵容。
- **对局工具**：商店和资金规划、预算顺序核验、持有库存与装备合成。
- **设置**：外观快捷键、画面识别校准、AI / API、数据来源四个分页。
- **悬浮终端**：优先展示建议，已追踪名单置顶；手动选择支持盟约、作用、类型与等阶筛选。底部“新对局（一键清空）”与首页共用重置逻辑，清空本局状态、追踪与标记，保持终端开启。

## 识别与建议

- 使用本地 PRTS 原始盟约图标识别开局信息，按盟约推算禁用干员；支持低难度全部启用、单人左右切组及局内重新核对。
- 稳定识别后锁定禁选内容。“设置 → 画面识别 → 稳定性与频率”分别设置禁选和商店的连续一致帧数（1–6 帧）；1 帧关闭连续等待，仍检查单帧可信度和完整性。商店追踪标记沿用商店帧数。
- 攻略路线可手动锁定，后续仍按本局禁选约束更新阶段建议。
- 商店按当前帧重新定位调度等级和商品位置；确认商品可独立更新，未确认卡位明确提示。
- 战场小人比对使用独立数据库。暂时漏识别的成员保留在阵容、盟约推荐与 AI 输入中并标为待核对，不能将暂不可见视作已离场。
- 追踪干员和装备出现时，在商品卡左侧显示右指表情；手动筛选、暂停识别和刷新建议保留本局追踪。新对局同步清空干员 / 装备追踪、各窗口置顶项、手动勾选及商店标记，并保存空名单。
- AI 为可独立关闭的自定义 API 教练。关闭时使用本地攻略；开启后发送当前局面、禁选约束与相关攻略材料，不上传截图。

助手只读取画面并提供建议，不替玩家购买、部署或操作游戏。

## 完整源码与构建

`GarrisonAssistant-0.1.23-CompleteSource.zip` 包含完整源码、测试、构建工具、资料数据库、头像与立绘库、战场小人库、盟约图标库、识别索引、动画模板和回放素材。

仓库直接提供可审阅的源码与较小资源。大型资源随 CompleteSource 包发布；**GitHub 自动生成的 Source code 压缩包不包含这些大型资源**。开发与重新构建请使用 CompleteSource 包。

需要 Windows 和 Python 3.13，部分规则对照检查另需 Node.js。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r desktop\requirements.txt
.venv\Scripts\python -m pip install --no-deps -r desktop\requirements-capture.txt
.venv\Scripts\python desktop\app.py
.venv\Scripts\python -m pytest desktop\tests -q
.venv\Scripts\python desktop\build_release.py
```

更多信息见 [开发说明](desktop/README.md)、[使用说明](desktop/使用说明.txt) 与 [更新记录](desktop/CHANGELOG.md)。

## 验证范围

0.1.23 通过 239 项自动测试、5 组相关离屏界面检查（包含 42 项追踪与新对局检查），以及 42 项打包程序自检。0.1.22 的独立帧数设置另经 28 项专项界面检查，0.1.23 已复跑；未修改的 OCR、模型和资源与上一完整回归版本逐文件核对。

本版使用保存画面回放、模拟数据与离屏界面验证，没有进行新的游戏实机操作或真实 AI 服务调用。结果不代表所有场景的识别准确率或攻略胜率。黄色采集边框已请求关闭，但系统可能忽略或回退；实际游戏表现尚待实测。
